# InternPay

## AI-First Verification with Human Dispute Resolution

InternPay is a blockchain-powered escrow platform designed to eliminate payment ghosting in freelance work and internships through AI-first verification, human dispute resolution, and blockchain-based escrow.

## 🔄 How InternPay Works

```text
Company Creates Contract
          ↓
Company Locks Funds in Escrow
          ↓
Student Submits Work
          ↓
AI Evaluates Submission
          ↓
AI Report Generated
          ↓
24-Hour Dispute Window
          ↓
   ┌───────────────┐
   │               │
No Dispute      Dispute
   │               │
   ↓               ↓
Auto Release   Human Judge
Payment        Reviews Evidence
                   ↓
          Release / Refund / Partial
```
